# Заводь

Спокойная игра про пруд с карпами. Один файл `index.html`, без сервера и без внешних ресурсов:
графика и музыка генерируются кодом. Открыть в браузере — и всё.

## Как играть

- **Коснуться воды** — покормить рыб. Сытые рыбы растут, взрослые роняют жемчуг.
- **Коснуться жемчужины** — собрать (через 30 с она соберётся сама).
- **Коснуться рыбы** — карточка: имя (можно сменить), порода, рост, гены, «отпустить в реку».
- **Нерест** — выбрать двух взрослых рыб, через 40 с из икры появляются мальки.
- **Атлас** — 52 породы и 4 особые черты (блеск, вуаль, призрак, сияние).
- **Сад** — расширение пруда, корм, кормушка, нерестилище, «Чутьё» (видны скрытые гены) и украшения, которые дают уют.
- **Желания** — плашка сверху: маленькие цели с наградой.

## Что держит

- Генетика: у каждого гена по два аллеля, сильный перекрывает слабый. Белый окрас, синий узор, «без узора»,
  блеск, вуаль и призрак — скрытые, проявляются только от обоих родителей. Сияние — редкая самопроизвольная мутация.
- Редкие рыбы дают больше жемчуга, поэтому разводить их выгодно.
- Пруд живёт и без игрока: за время отсутствия (до 12 часов) рыбы растут и копят жемчуг.

## Атмосфера

- Время суток как за окном (можно включить «всегда день/ночь»): закат, ночь с луной в воде, светлячки, фонарь.
- Время года по календарю: весной лепестки, осенью листья на воде, зимой снег.
- Иногда идёт дождь — рыбы ему рады (жемчуга ×1,5).
- Тихая пентатоника, плеск воды, колокольчик ветра.

Сохранение — в `localStorage` (ключ `zavod_v1`). Для отладки без заставки: `index.html?nointro`.
