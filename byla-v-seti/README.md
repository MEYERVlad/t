# «Была в сети»

True crime детектив от первого лица на Unreal Engine 5. Отдельный проект, не связан с игрой «ОМУТ» в корне репозитория.

- [docs/GDD.md](docs/GDD.md): дизайн-документ (механики, структура, ассеты, план прототипа)
- [docs/CASE_BIBLE.md](docs/CASE_BIBLE.md): вся правда о деле, таймлайн, улики, ложные следы, концовки (**спойлеры**)
- [BylaVSeti/](BylaVSeti/): проект Unreal Engine 5 (C++). **Как запустить: [BylaVSeti/INSTALL.md](BylaVSeti/INSTALL.md)**

## Состояние прототипа

| Готово | Дальше |
|---|---|
| Персонаж от первого лица, взаимодействие по E | Допрос с предъявлением улик (сейчас допрос — одно действие) |
| Служебный ноутбук: материалы дела, «Круг», почта, доска «СЛЕД», решения | Доска «СЛЕД» с перетаскиванием нитей мышкой (сейчас — выбор двух карточек и типа связи) |
| Живые посты и письма по таймерам и событиям | MetaHuman, озвучка, анимация лица |
| Версии-ловушки, доверие начальства, точка невозврата №1 | Голосования Twitch-чата |
| Сохранение состояния, данные дела в JSON | Режим «Стрим», настройки графики |
| Скрипт серой коробки уровня, проверка данных дела | Реальные ассеты окружения |

Сам проект Unreal (гигабайты ассетов, Git LFS) потом стоит перенести в отдельный репозиторий, чтобы не утяжелять этот.
