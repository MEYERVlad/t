# «Была в сети»

True crime детектив от первого лица на Unreal Engine 5. Отдельный проект, не связан с игрой «ОМУТ» в корне репозитория.

- [docs/GDD.md](docs/GDD.md): дизайн-документ (механики, структура, ассеты, план прототипа)
- [docs/CASE_BIBLE.md](docs/CASE_BIBLE.md): вся правда о деле, таймлайн, улики, ложные следы, концовки (**спойлеры**)
- [BylaVSeti/](BylaVSeti/): проект Unreal Engine 5 (C++). **Как запустить: [BylaVSeti/INSTALL.md](BylaVSeti/INSTALL.md)**
