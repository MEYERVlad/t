# «Была в сети»

True crime детектив от первого лица на Unreal Engine 5. Отдельный проект, не связан с игрой «ОМУТ» в корне репозитория.

- [docs/GDD.md](docs/GDD.md): дизайн-документ (механики, структура, ассеты, план прототипа)
- [docs/CASE_BIBLE.md](docs/CASE_BIBLE.md): вся правда о деле, таймлайн, улики, ложные следы, концовки (**спойлеры**)
- [BylaVSeti/](BylaVSeti/): проект Unreal Engine 5 (C++). **Как запустить: [BylaVSeti/INSTALL.md](BylaVSeti/INSTALL.md)**

## Состояние прототипа

| Готово | Дальше |
|---|---|
| Персонаж от первого лица, взаимодействие по E | Озвучка: система субтитров и реплик, сценарий для записи |
| Главное меню: продолжить, новое дело, настройки графики и экрана, выход | Реконструкция ссоры в машине (ползунок времени) |
| Служебный ПК: материалы дела, «Круг», почта, доска «СЛЕД», решения, стрим | Мимика лиц (моргание, губы по голосу) |
| Допрос: показания, «Предъявить улику», реакции, живой пост во время допроса | |
| Доска «СЛЕД»: карточки и нити перетаскиванием мышкой, цвета связей | |
| Сборка в .exe: настройки в проекте, инструкция [BylaVSeti/BUILD_EXE.md](BylaVSeti/BUILD_EXE.md) | |
| Живые посты и письма по таймерам и событиям, версии-ловушки, доверие | |
| Голосование Twitch-чата: плашка на экране, автоподключение к каналу, настройки графики, место под камеру | |
| Сохранение, данные дела в JSON, проверка данных, скрипты уровней | |
| Все локации оформлены паками с Fab (кабинет, квартира, архив, кафе, дача, суд) | |
| 7 персонажей MetaHuman с анимацией стояния, появление по сюжету | |
| Консольные команды для проверки: `BylaShowAll`, `BylaFlag <флаг>` | |
| Сюжет целиком: 4 акта, суд, 5 концовок, одно сплошное дело без глав | |

**Сюжет готов от начала до конца:** все 4 части и суд, 7 допросов, 52 улики, 5 концовок, 3 точки невозврата + 3 решения для голосования чата.

Сам проект Unreal (гигабайты ассетов, Git LFS) потом стоит перенести в отдельный репозиторий, чтобы не утяжелять этот.
