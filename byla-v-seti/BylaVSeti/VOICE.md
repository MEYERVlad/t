# Озвучка: как сделать и добавить в игру

В игре 59 реплик у 7 персонажей (допросы и суд). Полный список с текстом и подсказками, как играть, — **`VO_SCRIPT.md`**.
Каждая реплика — отдельный WAV-файл с точным именем из таблицы (например, `artem__never_touched.wav`).
Если файла нет, реплика просто показывается текстом, как раньше. Поэтому озвучивать можно постепенно.

Есть два пути, их можно смешивать (часть реплик синтезом, часть своим голосом).

## Путь 1. Черновая озвучка синтезом речи (бесплатно, 20–30 минут)

Голоса Silero: русские, звучат прилично, работают на вашем компьютере без интернета.
**Лицензия только для некоммерческого использования:** для стрима и тестов подходит, для платного релиза в RuStore голоса нужно будет записать самим.

1. **Установить Python** (один раз): python.org → Downloads → **Python 3.11** для Windows.
   В первом окне установщика **обязательно поставить галочку «Add python.exe to PATH»**, затем «Install Now».
2. Открыть папку `C:\Dev\BylaVSeti\BylaVSeti\Scripts\voice` → двойной клик по **`make_voices.bat`**.
3. Первый раз он скачает библиотеки (~300 МБ) и модель голоса (~100 МБ) — 5–15 минут. Потом озвучит все реплики.
4. Когда в окне появится «Готово», файлы лежат в `Scripts\voice\out`.

Переозвучить одного персонажа: открыть командную строку в этой папке и набрать `make_voices.bat kira --force`.

## Путь 2. Свой голос (лучше всего для стрима)

1. Поставить бесплатный **Audacity** (audacityteam.org). Микрофон — любой, хоть гарнитура; главное — тихая комната.
2. Открыть `VO_SCRIPT.md`, записывать **по персонажу за раз** (так проще держать голос).
3. Каждую реплику: запись → выделить лишнюю тишину в начале и конце → Delete →
   **Файл → Экспорт → Экспорт в WAV** → имя ровно как в колонке «Файл» (например, `irina__not_me.wav`),
   кодировка «Signed 16-bit PCM».
4. Голос для разных персонажей можно менять: Эффекты → **Смена высоты тона** (ниже — для Кулика и судьи, чуть выше — для Светы).

## Добавить файлы в игру (для обоих путей)

1. Открыть проект в Unreal.
2. Панель ресурсов → папка **Содержимое** → правой кнопкой → **Новая папка** → имя **`Voice`** (точно так, латиницей).
3. Открыть папку `Voice` в Unreal.
4. В проводнике открыть папку с WAV-файлами, выделить все (Ctrl + A) и **перетащить мышкой в панель ресурсов** Unreal.
5. **Сохранить всё** (Ctrl + Shift + S).
6. Проверка: Play → допрос Артёма (кабинет → допросная). Первое показание должно прозвучать сразу.
   Стрелки ← → листают показания — каждое звучит. Неверная улика — звучит отказ, верная — признание.

Заменить реплику: перетащить новый файл с тем же именем в ту же папку → Unreal спросит про замену → «Да» (Replace / Reimport).

## Настройки в игре

Главное меню → **Настройки → Озвучка персонажей**: Выкл / 50% / 75% / 100%.
Субтитры (текст реплик) показываются всегда.

## Если реплика не звучит

- Имя файла в Unreal должно точно совпадать с таблицей (без `.wav`, без пробелов, строчными буквами).
- Файл должен лежать прямо в `Содержимое/Voice`, не во вложенной папке.
- Текст реплики в игре поменялся — попросите обновить `VO_SCRIPT.md`, имена файлов при этом обычно не меняются.
