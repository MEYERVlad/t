# Чек-лист первого полного прохождения

Цель: пройти игру от начала до любой концовки и записать всё странное. Займёт 1,5–3 часа.
Не обязательно за один раз: игра сохраняется сама.

## Перед началом
- [ ] Проект собрался без ошибок (если нет — пришлите текст ошибки).
- [ ] Запущены скрипты `build_office.py`, `build_irina_flat.py`, `build_locations.py`.
- [ ] В Output Log по фильтру `LogCase` есть строка `Case loaded: evidence 52, ...`.
- [ ] Чтобы начать с нуля: ноутбук → «Стрим и игра» → «Начать заново».

## По ходу игры отмечайте
| Где | Что проверить |
|---|---|
| Кабинет | Подсказки «[E] …» появляются на всех предметах, ключи на стене видны |
| Ноутбук | Все разделы открываются, текст не вылезает за края, кнопки нажимаются |
| Доска «СЛЕД» | Карточки двигаются, нити тянутся от булавки, подписи нитей удаляют нить |
| Допросы | Стрелки листают показания, «Предъявить улику» работает, неверная улика снимает доверие |
| Пост во время допроса | Через ~20 с после признания Артёма сверху появляется баннер «Круг · прямо сейчас» |
| Поездки | Ключи переносят в нужную локацию, «Вернуться в отдел» работает, прогресс не теряется |
| Персонажи по сюжету | Кира в «Причале» появляется только после того, как вы её вычислили на доске |
| Суд | Судья принимает ответы уликами, «Завершить выступление» в «Решениях» показывает концовку |
| Twitch | «Стрим и игра» → подключиться к своему каналу → голосование → написать `1` в своём чате |

## Что прислать
- Скриншоты всего, что выглядит сломанным.
- Где вы застряли и помогла ли подсказка.
- Какая концовка вышла и сколько заняло прохождение.
- Что было скучно, а что зацепило.
