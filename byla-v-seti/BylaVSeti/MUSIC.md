# Фоновая музыка

## Почему не музыка из Minecraft
Музыка Minecraft (C418, Lena Raine) принадлежит Microsoft/Mojang. На Twitch за неё приходят жалобы правообладателя:
запись стрима глушат, а канал может получить страйк. Стримеру это навредит. Поэтому берём **свободную музыку**,
которую можно использовать в играх и на стримах. Похожее настроение (спокойное пианино, эмбиент) найти легко.

## Где брать (бесплатно и безопасно для стрима)
| Где | Лицензия | Что искать |
|---|---|---|
| **incompetech.com** (Kevin MacLeod) | CC BY 4.0 — бесплатно, нужно указать автора в титрах | раздел Royalty Free Music → жанр *Mystery*, *Soundtrack*, *Calming*. Для примера послушайте «Lightless Dawn», «Long Note Four», «Dark Times» |
| **pixabay.com/music** | Pixabay License — бесплатно, указывать автора не обязательно | `calm piano`, `ambient`, `mystery`, `dark ambient`, `detective` |
| **freemusicarchive.org** | разные CC | берите только CC BY или CC0 (не NC — «некоммерческие» не подойдут для RuStore) |

Не подходят: YouTube Audio Library (только для роликов на YouTube), музыка из игр, фильмов и сериалов, треки «no copyright» из случайных видео.

## Какие треки нужны
Имя ассета в Unreal — ровно как в таблице. Обязателен только **Theme**, остальное — по желанию.
| Имя | Когда играет | Настроение |
|---|---|---|
| **Theme** | главное меню и все локации без своего трека | спокойное, тревожное, «дождь за окном» |
| Interrogation | во время любого допроса | напряжённое, тихое, без мелодии на переднем плане |
| Ending | финальный экран | грустное, светлое |
| L_Office, L_IrinaFlat, L_LabArchive, L_Prichal, L_Dacha, L_Court | в своей локации | по месту: квартира — тихое пианино, дача — ночной эмбиент, суд — торжественно |

Трек играет по кругу, при смене — плавный переход. Если трека нет, продолжает играть предыдущий.

## Как добавить в игру
1. Скачать трек. Если он в **MP3** — открыть в бесплатном **Audacity** → Файл → Экспорт → **Экспорт в WAV**.
2. Назвать файл по таблице, например `Theme.wav`.
3. Unreal → Панель ресурсов → **Содержимое** → правой кнопкой → **Новая папка** → **`Music`**.
4. Перетащить WAV в папку `Music` → **Ctrl + Shift + S**.
5. Play — музыка заиграет сразу, в главном меню.
6. Записать трек и автора в `docs/CREDITS.md` (для CC BY это обязательно) — или прислать мне название, я впишу.

## Громкость
Главное меню → **Настройки → Музыка**: Выкл / 15% / 35% / 60%. По умолчанию 35% — чтобы не мешала голосам и стримеру.
