# Персонажи MetaHuman: кого и как делать

Схема одна для всех (проверена на Артёме):
1. Панель ресурсов → папка `Characters` → новая папка с именем персонажа → правой кнопкой → **MetaHuman → MetaHuman Character**.
   **Имя файла строго `MHC_<Имя>`** (латиницей, как в таблице ниже): по нему скрипт найдёт персонажа.
2. Открыть → **Заготовки**: выбрать похожего человека → **Голова и тело / Волосы и одежда** — подправить.
3. **Создать полный каркас** (если «Server Error» — повторить; у Артёма со второго раза получилось).
4. **Сборка** → **Собрать** → закрыть редактор персонажа → **Сохранить всё**.
5. Когда сделаете одного или нескольких — **Tools → Execute Python Script → `Scripts/place_characters.py`**.
   Скрипт сам поставит всех готовых на место цилиндров, повернёт и включит анимацию. Кого ещё нет — пропустит.

## Анимация в проект (делается один раз)
Анимация стояния лежит внутри плагина MetaHuman, в папке `Optional`. В редакторе она работает,
но при загрузке уровня даёт ошибки «Unable to identify a valid mount point», а в готовую игру (.exe) не попадёт.
Поэтому копируем её к себе:
1. Панель ресурсов → шестерёнка **Настройки** (справа вверху панели) → включить **Показать содержимое плагинов** (Show Plugin Content).
2. В поиске панели набрать `AS_MH_Neutral_Stand_Idle_Loop` (искать во всех папках, слева выбрать самый верх — «Все»).
3. Правой кнопкой по анимации → **Действия с ассетом → Расширенное копирование** (Asset Actions → Advanced Copy).
4. Папка назначения: `Content/Characters/Animations` (создайте, если нет) → **OK**. Скопируется анимация вместе со скелетом, ссылки поправятся сами.
5. **Сохранить всё** → запустить `place_characters.py` ещё раз — он сам возьмёт копию из проекта.
6. Проверка: запустить `Scripts/check_plugin_refs.py`. Если в Output Log написано «Чисто» — готово.
   Если нет — пришлите файл `Saved/plugin_refs.txt` из папки проекта, там будет видно, кто ещё ссылается на плагин.

Предупреждения `CreateExport ... AnimGraphNodeBinding_Base_0` — безобидные (служебные данные редактора в анимационном блупринте MetaHuman), на игру не влияют.

## Если что-то не так
- **Персонажи стоят боком или спиной** — в начале `place_characters.py` поменяйте `FACING_OFFSET = -90.0` на `90.0` (или `0.0` / `180.0`) и запустите снова.
- **После `build_*.py` персонажи исчезли** — так и задумано: build-скрипты пересоздают локацию. Просто запустите `place_characters.py` ещё раз.
- **Тормозит** — когда персонажей станет много, пересоберём их в облегчённом варианте (в «Сборке» вместо «UE Cine» выбрать вариант Optimized, если он есть).
