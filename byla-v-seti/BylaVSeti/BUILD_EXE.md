# Как собрать игру в .exe

После сборки игра запускается двойным кликом по `BylaVSeti.exe`, без Unreal Engine.
Папку с игрой можно заархивировать и отдать стримеру.

## Перед первой сборкой (один раз)

1. **Место на диске.** Нужно свободно минимум **60 ГБ** на диске с проектом и **20 ГБ** там, куда будет собрана игра.
   MetaHuman-персонажи тяжёлые, сама игра получится примерно 5–15 ГБ.
2. **Проверить, что игра запускается в редакторе.** Открыть `L_Office` → Play → главное меню → «Новое дело» → пара шагов. Закрыть Unreal.
3. **Файл настроек сборки уже лежит в проекте** (`Config/DefaultGame.ini`): в нём перечислены все 6 локаций, режим Shipping
   (финальная версия без консоли и отладки) и папка с данными дела. Ничего настраивать вручную не нужно.

## Сборка

1. Открыть проект (`BylaVSeti.uproject`).
2. **Сохранить всё:** Ctrl + Shift + S.
3. Верхнее меню **«Платформы» → «Windows» → «Упаковать проект»** (Platforms → Windows → Package Project).
   - Если в меню «Платформы» есть выбор конфигурации (Binary Configuration), выбрать **Shipping**.
4. Откроется окно выбора папки. Создать и выбрать, например, `C:\Dev\BylaVSeti_Build`. **Не внутри папки проекта.**
5. Справа внизу появится плашка «Упаковка проекта…» со ссылкой **«Показать журнал»** (Show Output Log). Нажать её — там видно, что происходит.
6. Ждать. **Первая сборка долгая: от 30 минут до 2 часов** (Unreal заново готовит все шейдеры и текстуры). Компьютер в это время лучше не нагружать.
   Следующие сборки — 5–20 минут.
7. Готово, когда в журнале появится **`BUILD SUCCESSFUL`**, а плашка напишет «Упаковка завершена».

Результат: папка `C:\Dev\BylaVSeti_Build\Windows\` с файлом **`BylaVSeti.exe`** внутри.

## Проверка

1. Открыть `C:\Dev\BylaVSeti_Build\Windows\` → двойной клик по `BylaVSeti.exe`.
2. **Первый запуск может минуту-две показывать чёрный экран или тормозить** — игра готовит шейдеры под видеокарту. Это один раз.
3. Должно появиться главное меню. Проверить:
   - «Новое дело» → кабинет, служебный ПК открывается по E;
   - переход в другую локацию (ключи от машины на доске у двери);
   - «Выйти из игры» в ПК (раздел «Стрим», в самом низу) закрывает игру;
   - повторный запуск → «Продолжить дело» продолжает с того же места.

## Как отдать стримеру

1. Правой кнопкой по папке `Windows` → **«Сжать в ZIP-файл»** (или 7-Zip — сожмёт сильнее).
2. Залить архив на Яндекс Диск / Google Диск и отправить ссылку.
3. Стримеру: распаковать в любую папку **без русских букв в пути** (например, `C:\Games\BylaVSeti`) и запустить `BylaVSeti.exe`.
   Если Windows покажет «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае»
   (игра не подписана сертификатом, так бывает у всех инди-сборок).
4. Сохранения стримера лежат в `%LOCALAPPDATA%\BylaVSeti\Saved\SaveGames` и не пропадут при обновлении игры.
5. Подключение чата: в игре служебный ПК → «Стрим» → ввести имя канала → «Подключить». Пароли и токены не нужны.

## Если сборка упала

- В журнале найти первую красную строку с **`Error`** (поиск по журналу: `Error`).
- Полный журнал сборки: `C:\Users\<имя>\AppData\Roaming\Unreal Engine\AutomationTool\Logs\...\Log.txt`
  (путь к нему пишется в самом конце журнала в редакторе).
- Прислать в чат скриншот красных строк или этот `Log.txt` — разберёмся.

Частые причины:
| Сообщение | Что делать |
|---|---|
| `Unable to find/load ... /MetaHumanCharacter/Optional/...` | Запустить `Scripts/check_plugin_refs.py` и прислать результат |
| `Missing ... Windows SDK` / `No compiler` | Visual Studio Installer → «Изменить» → включить «Разработка классических приложений на C++» и Windows SDK |
| `Not enough space` / `disk full` | Освободить место (см. выше) |
| Сборка прошла, но в игре нет текстов/кнопки пустые | Проверить, что рядом с игрой есть папка `Windows\BylaVSeti\Content\Data\Case` с файлами `.json` |
