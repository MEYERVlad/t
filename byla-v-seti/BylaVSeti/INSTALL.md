# Как запустить прототип «Была в сети» (пошагово, для новичка)

Займёт 1–2 часа, почти всё это время уходит на скачивание. Нужно около **100 ГБ** свободного места.

---

## Шаг 1. Установить Unreal Engine

1. Скачайте и установите **Epic Games Launcher**: https://store.epicgames.com/download
2. Откройте его → слева **Unreal Engine** → вкладка **Библиотека (Library)** → жёлтый **«+»** рядом с «Версии движка».
3. Выберите **последнюю версию 5.x** (5.6 или новее) → **Установить**.
4. Чтобы сэкономить место: перед установкой нажмите **Параметры (Options)** и снимите галочки с Android, iOS, Linux.

## Шаг 2. Установить Visual Studio 2022 (нужна для C++)

1. Скачайте **Visual Studio 2022 Community** (бесплатно): https://visualstudio.microsoft.com/ru/vs/community/
2. В установщике отметьте наборы:
   - **«Разработка игр на C++»** (Game development with C++)
   - **«Разработка классических приложений на C++»** (Desktop development with C++)
3. Справа в деталях набора «Разработка игр на C++» проверьте, что стоят **Windows 11 SDK** (или 10) и **MSVC v143**.
4. Установите. Если установщик предложит перезагрузку, перезагрузитесь.

## Шаг 3. Скачать проект

1. Откройте https://github.com/meyervlad/t
2. Слева сверху переключите ветку на **`claude/new-session-gsu6ql`**.
3. Зелёная кнопка **Code → Download ZIP**.
4. Распакуйте архив. Внутри найдите папку `byla-v-seti/BylaVSeti`.
5. **Скопируйте её в `C:\Dev\BylaVSeti`**.

> ⚠️ В пути к проекту **не должно быть русских букв и пробелов**: Unreal из-за них падает при сборке.
> `C:\Dev\BylaVSeti` подходит, а `C:\Users\Влад\Рабочий стол\...` нет.

## Шаг 4. Собрать проект

1. Откройте `C:\Dev\BylaVSeti`.
2. Нажмите **правой кнопкой** на `BylaVSeti.uproject` → **Switch Unreal Engine version…** → выберите установленную версию → OK.
   (В Windows 11 сначала нажмите «Показать дополнительные параметры».)
3. Снова правой кнопкой → **Generate Visual Studio project files**.
4. Дважды щёлкните `BylaVSeti.uproject`.
5. Появится окно *«The following modules are missing or built with a different engine version… Would you like to rebuild them now?»* → **Yes / Да**.
6. Ждите 3–10 минут. Первый запуск редактора долгий: он компилирует шейдеры, проценты видны внизу справа.

**Если появилась ошибка «could not be compiled»:**
1. Откройте `BylaVSeti.sln` (появился в папке после пункта 3).
2. Наверху выберите **Development Editor** и **Win64**.
3. Справа в «Обозревателе решений» правой кнопкой на **BylaVSeti** → **Собрать (Build)**.
4. Скопируйте текст ошибок из окна **«Список ошибок»** или **«Вывод»** и пришлите мне. Я исправлю.

## Шаг 5. Построить уровень

1. В редакторе: меню **Tools → Execute Python Script…**
2. Выберите файл `C:\Dev\BylaVSeti\Scripts\build_office.py`.
3. Скрипт сам создаст уровень `Maps/L_Office`: кабинет следователя, дверной проём, допросную, мебель, предметы дела, свет.
4. Внизу в **Output Log** должна появиться строка `[build_office] Готово`.

Скрипт можно запускать повторно: он пересоздаёт только свои объекты (с меткой `GEN_`) и не трогает то, что вы добавили руками.

## Шаг 6. Играть

Нажмите **▶ Play** наверху (или **Alt+P**).

| Клавиша | Действие |
|---|---|
| **W A S D** | ходить |
| **Мышь** | смотреть |
| **E** или **ЛКМ** | взаимодействовать (подсказка появляется под прицелом) |
| **Tab** | закрыть ноутбук |
| **Shift+F1** | освободить мышь в редакторе |
| **Esc** | остановить игру в редакторе |

**С чего начать (без спойлеров):** подойдите к ноутбуку на столе. Почитайте почту, «Круг» и материалы дела.
Потом изучите предметы в кабинете, вызовите Артёма и допросите его в соседней комнате.
Попробуйте собрать версии на доске «СЛЕД» и принять решение в разделе «Решения». Прототип рассчитан на 15–25 минут.

## Шаг 7. Проверить, что данные дела загрузились

**Window → Output Log**, в строке поиска введите `LogCase`. Должна быть строка:

```
Дело загружено: улик 18, постов 12, версий 4, решений 1, предметов 5, строк UI ...
```

Если там нули или ошибка «Не удалось прочитать», значит в проекте нет папки `Content/Data/Case`. Проверьте, что вы скопировали папку проекта целиком.

## Что прислать мне после первого запуска

- Получилось ли собрать (если нет, то текст ошибки).
- Скриншот кабинета в игре.
- Где было непонятно или неудобно.

## Как устроен проект

| Папка | Что внутри |
|---|---|
| `Source/BylaVSeti/Public/Case`, `Private/Case` | Логика расследования: улики, флаги, доверие, посты по таймерам, доска «СЛЕД», решения, сохранение |
| `Source/BylaVSeti/.../Gameplay` | Персонаж от первого лица, предметы, ноутбук, режим игры |
| `Source/BylaVSeti/.../UI` | Интерфейс: HUD и ноутбук. Всё собирается в коде, Widget Blueprint не нужен |
| `Content/Data/Case/*.json` | **Всё содержание дела**: улики, посты, письма, версии, решения, предметы, тексты интерфейса. Меняется без перекомпиляции, достаточно перезапустить игру |
| `Scripts/build_office.py` | Строит уровень |
| `Scripts/validate_case.py` | Проверяет, что в данных дела нет битых ссылок: `python Scripts/validate_case.py` |
