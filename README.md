# ОМУТ

Сюжетный point-and-click хоррор-квест в духе *Slender Threads*. Осень 1996-го, городок Тихий Омут
на берегу водохранилища, под которым лежит затопленное село. Коммивояжёр Лев Гордеев видит будущее —
и пытается его изменить.

Игра завершена: **пять глав и три концовки** (≈2 часа) — «Приезд», «Город», «Покровское», «Нити», «Омут»:
ночь у воды и дневной город, видения, сборка видения из обрывков, продажа энциклопедий, тёмный архив с лучом фонарика,
нити между людьми и водой, лодка в тумане по звуку колокола, затопленная церковь, где нельзя смотреть в лица,
ночная карта города с часами и выбором, кого спасать, зеркало с затопленной комнатой, нить, которую надо перенести руками,
видение собственной смерти, Изнанка — два мира на одном месте, возвращение имён утонувшим, финальный монтаж.
Концовки: **«Берег»**, **«Омут»** и скрытая **«Покров»**. На титуле — **достижения** по всем главам (27 штук, часть скрыта). Вся графика и весь звук генерируются кодом — ни одной картинки
или аудиофайла.

## Как запустить

Открыть `index.html` в браузере. Сервер не нужен. Лучше в наушниках.

Один файл для пересылки: `node tools/build.js` → `dist/omut.html`.

## Управление

- **ЛКМ / касание** — идти, действовать, говорить.
- **ПКМ / долгое касание** — осмотреть.
- **Вещи** — внизу экрана (подведите курсор к нижнему краю). Выберите предмет и нажмите на объект в мире.
  Повторное нажатие на предмет — рассмотреть. Энциклопедия в инвентаре — подсказка, если застряли.
- **Двойной клик по выходу** — мгновенный переход.
- **Пробел / T / глаз в углу** — нити (с главы 3).
- **Лодка:** зажать левую/правую половину экрана или ←/→ — поворот.
- **Нить Зинаиды (глава 4):** в режиме нитей зажать нить и вести; когда за окном тянут — замереть.
- **Изнанка (глава 5):** кнопка ⇅ или F — перевернуть мир; курсор на лице утонувшего — всмотреться.
- **Esc** — пауза.

## Трейлер

`trailer.html` — кинотрейлер (84 с), смонтированный из сцен игры; музыка и звук тоже генерируются.
Видео 1080p со звуком: `node tools/trailer-export.js dist/omut-trailer.mp4` (нужны Playwright и ffmpeg).
Озвучка: сценарий и требования к записи — [`docs/VOICEOVER.md`](docs/VOICEOVER.md), файлы — в `assets/vo/`.

## Разработка

- Дизайн-документ всей игры: [`docs/GDD.md`](docs/GDD.md).
- Быстрый переход к сцене: `index.html?scene=pier&flags=vision,zinaSleeps&inv=book,bell`.
- Автопрохождение глав с проверкой ошибок: `node tools/playthrough.js shots`, `node tools/playthrough2.js shots`, `node tools/playthrough3.js shots`, `node tools/playthrough4.js shots`, `node tools/playthrough5.js shots` (нужен Playwright; в главах 4–5 — по три маршрута).
- Стенд персонажей: `tools/figures.html`.

## Заводь

В папке [`pond/`](pond/) лежит отдельная спокойная игра «Заводь» — пруд с карпами, разведение и атлас пород. Открыть `pond/index.html`.
