# НЕГАТИВ · Глава I «Выдержка»

Концепт отдельной игры (не часть «Омута»): сюрреалистический оккультный point-and-click, одна комната из четырёх стен.

- `GDD-glava-1.md` — дизайн-документ главы: лор, раскадровка стен, паспорт персонажей и предметов, цепочка пазлов.
- `index.html` — играбельный прототип. Открыть в браузере, сервер не нужен. Вся графика рисуется кодом (SVG), звук синтезируется.
- `src/page.html` — исходник страницы; `node build.js` вставляет в неё документ и пересобирает `index.html`.
